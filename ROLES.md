# Group Roles

Use this file to decide who is responsible for each part of the project.

## Person 1: Frontend Designer

Branch:

- `frontend-ui`

Main files:

- `index.html`
- `styles.css`

Responsibilities:

- Build the main page layout
- Add and organize buttons, labels, and controls
- Choose colors, spacing, and font styling
- Make the app easy to understand and use
- Check that the app looks good on different screen sizes

## Person 2: Drawing Feature Developer

Branch:

- `drawing-engine`

Main file:

- `drawing.js`

Responsibilities:

- Make the canvas drawing work
- Add brush size and brush color behavior
- Add drawing tools like clear, eraser, undo, or redo
- Fix drawing bugs
- Test mouse, trackpad, and touchscreen input if possible

## Person 3: Project Manager and Tester

Branch:

- `project-setup-docs`

Main files:

- `README.md`
- `TESTING.md`
- `ROLES.md`

Responsibilities:

- Keep instructions updated
- Write how to run the project
- Track what still needs to be finished
- Test the app and write down bugs
- Help review pull requests before merging into `main`

## Team Rule

Each person should work on their own branch. When a role is finished, open a pull request into `main` so the group can review it.
